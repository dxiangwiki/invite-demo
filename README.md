# invite-demo
招聘沟通角色反转演示页面

## ✨ 项目介绍
模仿招聘平台页面，反转传统招聘交互逻辑：
不再是求职者主动去联系企业，而是企业HR主动向求职者发起沟通邀约。
求职者拥有选择权，可以【接受沟通】或者【婉拒邀约】。

## 🚀 在线预览
https://dxiangwiki.github.io/invite-demo

## 📄 功能
- 邀约列表切换查看不同企业邀约
- 婉拒邀约弹窗，可选择拒绝理由
- 接受沟通，弹出简易聊天窗口，支持发送消息
- 页面布局参考招聘网站，纯前端静态页面，无需后端

## 🛠 技术
HTML + TailwindCSS + 原生JavaScript
